# War---Python-Simple-Card-Game
NO AI - War built in python

RULES
War is a game in which each person gets half the deck and flips up a card each turn. 
The higher value wins, 
however if the same value for both people is drawn Each person places 3 cards for bet and the winner of the next round takes the heap

CONTROLS
press enter to play a card
